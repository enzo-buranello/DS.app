# Claude Code

Lisez START_HERE.md et AGENTS.md : ce sont les instructions communes du projet.
Le chat Claude intégré passe par `connectors/agents/claude.ts` (`claude -p`
sans outils, non qualifié sur toutes les plateformes). Vous pouvez modifier le
starter depuis votre terminal avec vos propres permissions. Figma : voir
`figma-plugin/README.md`. Pour les tokens, lisez explicitement
`.agents/skills/token-change/SKILL.md`. N’importez aucun cache de compte.
